Se connecter avec Trello

Un clic, tu arrives sur une vraie page Trello où tu autorises l'accès depuis ton propre compte. Le jeton reste ensuite dans ce navigateur : chaque nouvel ordinateur ou navigateur redemande cette connexion une fois, puis reste connecté. Pour révoquer l'accès, va dans les paramètres Trello, section Applications autorisées.
