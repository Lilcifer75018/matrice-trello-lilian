Le bouton ne fonctionne pas ?

Trello n'accepte le retour automatique que si l'adresse de cette page est déclarée dans les réglages de la clé API. Sans attendre ce réglage, cette méthode marche toujours :

  1. Ouvrir la page d'autorisation Trello, cliquer sur « Allow ».
  2. Trello affiche un long code. Copie-le et colle-le ici.

Le jeton reste dans ce navigateur : chaque nouvel ordinateur redemande cette connexion une fois. Le classement et l'historique, eux, vivent dans Trello et te suivent partout. Pour révoquer l'accès : paramètres Trello, section Applications autorisées.
